Unix Directories
`bin` Essential command binaries
`boot` Static files of boot loader
`dev` Device files
`etc` Host-specific sys conf
`home` home directory for all users
`lib` Essential shared libs and kernel modules
`media` mnt point for removable media
`mnt` mnt point for mounting a filesystem temporarily
`opt` Add-on app softeare package
`root` Home dir of root user
`sbin` Essential system binaries
`srv` Data for services provided by system
`tmp` temp files purged on reboot
`usr` Secondary hierarchy
`var` Variable data
