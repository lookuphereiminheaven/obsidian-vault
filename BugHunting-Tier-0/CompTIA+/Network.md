##### **Introduction to Networks**
- **Network**: Interconnected or interrelated chain, group or system
-  **Network Model**
  - Centralized *(Tyranny)*
  - Client/Server *(Democracy)
  - Peer to Peer (Workgroup) *(Communism)
  - Mixed Mode Network
- **Common Network components**
  1. Workstations: Powerful computers that run more than one CPU and with resources available to other users
  2. Servers: Provides resources like addressing, manages devices on network and controls network-wide functions like permissions
  3. Host
- **Computer Network**: Two or more computers connected with the purpose of communicating data electronically
  - LAN - Local Area Network
    - Small area
    - Mostly Ethernet
    - Nodes are directly connected to one another by cable or short-range wireless
    - No need to be leased from a service provider
  - [WAN](WAN) - Wide Area Network
    - Large area, often multiple areas
    - Connects multiple LANs
    - Uses long-range communication like satellite, radio frequency
    - Can be public (world's largest WAN is the internet) or private
    - Types of WAN
      - PAN - Personal Area Network (Bluetooth)
      - CAN - Campus Area Network
      - MAN - Metropolitan Area Network
      - GAN - Global Area Network
      - EN - Enterprise Network (uses both WAN & LAN)
  - Internet - World's Largest GWAN
  - Intranet - Private Version of the Internet
  - Extranet - Like Intranet but Open to Limited Outside Sources
- **Segment**: Portion of Network with Linked Devices Separated by a Connectivity Device
- **Node**: Any device connected to a communication network
- **Network Backbones**
  1. Serial: One backbone cable, multiple switches
  2. Hierarchical/Distributed: Easy management, typical for LANs, easily scalable
  3. Collapsed: Uses a Router as the connecting point
  4. Parallel: Like collapsed but with multiple cable connections, great for redundancy
- **Terminal**
  - No processing of its own
  - No memory of its own
  - Terminal emulator needed
- **Client**
  - Has its own processor
  - Has memory of its own
- **Peer**
  - Provides its own resources and services
  - Self managed and self contained
 - **Network Connections**
  1. Point To Point: A direct connection between two nodes on a network
  2. Multipoint: Nodes on network connect to two or more nodes simultaneously
     - Signals are not private
  3. Radiated: A wireless connection or a Broadcast connection that can be either P2P or Multipoint
